# Student Performance Analysis Dashboard

## About the Project

This project analyzes student marks, attendance, and study hours to understand student performance.

I used Python and Pandas for data cleaning and analysis, Excel for the dataset, and Power BI to create an interactive dashboard.

## Problem Statement

It is difficult to understand student performance from marks and attendance data manually.

This project helps analyze subject-wise marks, attendance, study hours, and overall performance.

## Objectives

- Clean and prepare student data.
- Analyze subject-wise marks.
- Find average percentage and attendance.
- Identify top-performing students.
- Analyze attendance and study hours.
- Identify students who need improvement.
- Create an interactive Power BI dashboard.

## Tools and Technologies

- Python
- Pandas
- Excel
- Power BI

## Dataset

The dataset contains data of 50 students.

It includes:

- Student ID
- Name
- Gender
- Math
- Science
- English
- Attendance
- Study Hours
- Total Marks
- Percentage
- Performance

## Python Analysis

Using Python and Pandas, I performed:

- Data loading
- Missing value checking
- Duplicate checking
- Data cleaning
- Subject-wise average marks
- Top 5 students analysis
- Attendance analysis
- Study hours analysis
- Performance category analysis
- Students needing improvement

## Power BI Dashboard

The dashboard contains:

- Total Students
- Average Percentage
- Average Attendance
- Subject-wise Average Marks
- Performance Distribution
- Study Hours vs Percentage
- Attendance vs Percentage
- Performance slicer
